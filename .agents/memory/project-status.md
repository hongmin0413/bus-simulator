# 專案現況

## 已完成
- 城市：6×6 街廓的棋盤道路（雙向各兩線、靠右行駛）、建築、公園、標線、25 個有紅綠燈的路口。每次重新整理建築會重新隨機產生。
- 關卡：三關（新手練習 4 站、市區環線 8 站、下班尖峰 10 站），設定都在 `js/levels.js`，加關卡只要加一筆。跑完一圈結算星等，最佳紀錄與轉向靈敏度存在瀏覽器 localStorage。下一站有綠色光柱與黃色停靠區。
- 選單：開場選關卡；遊玩中左上角「II」暫停，可繼續、重新開始、換關卡（選關卡畫面有「取消」可回到暫停選單，進度不變）、調轉向靈敏度。校正方向盤只在遊戲畫面的按鈕上，選單裡依使用者要求拿掉了。切到別的 App 會自動暫停。
- 全螢幕：開啟網頁後第一次點畫面就進全螢幕；開始畫面右上角、遊戲中「II」下方各有一個切換鈕（暫停選單裡的依使用者要求拿掉了）。自己按鈕退出後不會再自動進去；用返回鍵退出則會暫停，按「繼續」再進全螢幕。
- 載客：停進停靠區、車速為 0 才能開門；乘客先下後上，每人車資 15；完美停靠 +20、準點 +30、完成一圈 +100。
- 扣款：闖紅燈 −100、超速（超過 56 km/h 持續 2 秒）−20、撞人行道或車輛 −50。
- 車流：小客車、計程車、藍色小貨車、機車，數量依關卡。會等紅燈、跟車、遇到公車減速；機車貼路邊或鑽車縫，會從汽車旁邊鑽到前面。汽車不會變換車道超車。機車在有紅綠燈的路口左轉走兩段式（停待轉區）。
- 路況：斑馬線與行人（`js/peds.js`）、路邊違停（閃雙黃燈，車輛會繞過）、機車待轉區。扣款：未禮讓行人 −60、撞到行人 −200。
- 駕駛：手排 6 速 + R + N，真實離合器模型（見 reference-driving-model.md）。
- 操作配置：左下方向燈（上）＋離合器（類比）；右下車門／視角／校正＋拖曳式排檔（上排 1 3 5、中間空檔、下排 R 2 4 6；排檔桿自由跟手，不用照 H 槽走，可直接拖到任何檔位）＋手煞車、煞車、油門（下，踏板為類比且都從 0 開始）；中下檔位、時速、轉速表，其上方為方向燈指示、雙黃燈開關、手煞車指示。
- 手煞車、方向燈、雙黃燈：邏輯在 `js/signals.js`。手煞車開場與「回上一站」後是拉起的；方向燈在方向盤打超過四成再回正後自動取消。目前沒有「沒打方向燈」的扣款。
- 視角：駕駛座（左駕，預設，駕駛艙有儀表、窗框、車門、投幣箱等）、車外（預設在正後方，拖曳畫面可繞著公車看）。俯視已依使用者要求拿掉。
- 後照鏡：左上、右上各一面，右後照鏡左邊有一面廣角圓鏡照車門側；小地圖在圓鏡左邊。
- 聲音：全部用 Web Audio 合成（柴油引擎多層振盪器＋爆震噪音、渦輪、路噪、風切、氣煞洩氣、換檔、打齒、啟動馬達、開關門提示音、倒車警示音、碰撞）。
- 啟動：`start.bat`；本機伺服器 `server.js`（HTTP 8765、HTTPS 8766）。

## 尚未在手機實測（都只在電腦上用模擬驗證過邏輯）
- 觸控版面在實際手機尺寸下會不會擠、踏板大小是否好按。
- 左手離合器＋右手排檔同時操作的手感，離合器接合點是否好抓。
- 旋轉手機轉向：使用者實測後說問題是輪胎轉角太小，已加大（最小迴轉半徑約 5.6 公尺）；之後使用者仍覺得慢，再把三段靈敏度調成約 23／16／11 度打到底並加快反應。調整後尚未回報。
- 拖曳排檔的手感，以及排檔槽大小在手機上好不好拖。
- 下班尖峰關卡（74 輛車）在手機上的效能。
- 聲音聽起來像不像；合成音有上限，要更真實得改用錄音素材。
- 三面後照鏡對手機效能的影響。
