# 專案現況

## 已完成
- 城市：6×6 街廓，路口間距 100 公尺。三種道路（大道單向三線、一般道路兩線、巷道一線），最外側車道 4.6 公尺寬；路是彎的、路口不是正直角、轉角是半徑 6～10 公尺的圓角（做法見 reference-world-model.md）。建築、公園每次重新整理會重新隨機產生。
- 標線：雙黃線（巷道是黃虛線）、白虛線車道線（接近路口改白實線）、路面邊線、停止線、機車停等區、斑馬線、機車待轉區。
- 紅綠燈：25 個路口。橫桿上的橫式燈頭加桿上輔助燈頭、紅燈倒數、行人號誌（小人與倒數）。週期 36 秒。沒有左轉箭頭時相。
- 關卡：三關（新手練習 4 站、市區環線 8 站、下班尖峰 10 站），設定在 `js/levels.js`。跑完一圈就結束並結算星等（結算畫面只有重新開始、選擇關卡）。最佳紀錄、轉向靈敏度、畫面模式存在瀏覽器 localStorage。下一站有綠色光柱與黃色停靠區；上方顯示第幾站，小地圖標站序。
- 選單：開場選關卡；遊玩中左上角「II」暫停，可繼續、重新開始、換關卡（可取消）、調轉向靈敏度、開關聲音。畫面固定每秒 60 格。切到別的 App 會自動暫停。
- 全螢幕：開啟網頁後第一次點畫面就進全螢幕；開始畫面右上角、遊戲中「II」旁邊各有一個切換鈕。
- 載客：停進停靠區、車速為 0 才能開門；乘客先下後上，每人車資 15；每站最多 12 人候車（下班尖峰關卡 1.6 倍）；完美停靠 +20、準點 +30、完成一圈 +100。
- 扣款：闖紅燈 −100、超速 −20、撞人行道或車輛 −50、未禮讓行人 −60、撞到行人 −200、逆向 −60、轉彎未打方向燈 −30、變換車道未打方向燈 −20、進站未打右燈與出站起步未打左燈各 −20、行車不平順（急煞、煞停太頓、起步或換檔太猛）各 −10。交通違規的判定在 `js/rules.js`。
- 車流：小客車、計程車、藍色小貨車、機車。會等紅燈、跟車、遇到公車減速；轉彎前打方向燈並提前換車道、有煞車燈、綠燈起步有反應時間、左轉禮讓對向直行車；機車貼路邊或鑽車縫，紅燈時停進機車停等區，左轉走兩段式。汽車不會變換車道超車。路邊違停只出現在兩線以上的路。
- 公車：長 12、寬 2.5、高約 3.5（含冷氣）、軸距 6、前懸 2.7、後懸 3.3 公尺，取 12 公尺級甲類大客車的常見值（不是查統計算出的平均）。車身模型的座標照「z = -3 到 9」寫，整組再後移 `BODY_Z`，改模型時要注意。
- 駕駛：手排 6 速 + R + N，真實離合器模型（見 reference-driving-model.md）。開場引擎熄火，要踩離合器並按住「發動」約一秒；引擎運轉中、車子停住時再按一次是熄火。載客上限 65 人，乘客越多加速越慢、煞車距離越長。
- 操作配置：左上（收入旁）是暫停、全螢幕、視角、校正；左下方向燈（上）＋離合器；右下拖曳式排檔（上；桿子跟著手指，在檔位上只能沿那一排動，退回空檔才能換排，R 有擋塊）、煞車（寬）與油門（細長）（下）；中下的上排是喇叭、雙黃燈、車門、雨刷，下排是手煞車、儀表（指針式時速表、方向燈指示夾著檔位與警示燈、指針式轉速表）、發動鈕。中下整組往左偏 35px；指針表依螢幕寬度分三段（不到 640px 只留數字）。使用者手機約 640×330。
- 視角：駕駛座（左駕，預設）、車外（拖曳環繞、兩指捏合或滾輪縮放，切換時記住位置，重新開始時回到駕駛座）。行車視野輔助畫面：倒車顯示車後、打方向燈顯示那一側。雨刷可開關（還沒有雨天）。
- 後照鏡：左上、右上各一面；右後照鏡左邊的圓鏡照車頭正前方與右前角的死角；小地圖在圓鏡左邊。
- 聲音：全部用 Web Audio 合成。有下車鈴、空氣乾燥器排氣、啟動馬達聲。引擎、路噪、風切會經過「車廂」層（駕駛座視角較悶較小）；方向燈喀噠聲不經過，比引擎聲明顯。
- 分享：`index.html` 有 description 與 og 標籤，圖片是 `images/og-image.png`（網址寫死成 GitHub Pages 的絕對路徑）。
- 啟動：`start.bat`；本機伺服器 `server.js`（HTTP 8765、HTTPS 8766）。
