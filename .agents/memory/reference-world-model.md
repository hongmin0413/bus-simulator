# 道路與座標模型（2026-11-12 重做）

## 兩套座標
- 「格子座標」：道路是直的棋盤，路口在 `(i * CELL, j * CELL)`。車流、行人、站牌、停靠區、違規判定全部用這套算。
- 「世界座標」：畫面與公車物理用的。由格子座標經 `warp(x, z)` 平滑推歪（x 方向隨 z 做正弦位移、z 方向隨 x 做正弦位移，斜率最大約 0.26），所以路會彎、路口夾角約 62～118 度。
- 轉換函式都在 `js/config.js`：`warp`、`unwarp`（反覆代入 5 次）、`warpH`、`unwarpH`（朝向）。
- 公車：`bus.x / z / h` 是世界座標（後軸中心）；`bg`（`js/state.js`）是車身中心的格子座標與朝向，每格由 `refreshGrid()` 更新。`placeBusAt(x, z, h)` 的參數是格子座標。
- 其他車輛、行人的 `x / z / h` 是格子座標，擺模型時才 `warp`。
- 新增任何會擺到場景裡的東西：位置先用格子座標算，再 `warp`；長條的東西（標線）要切成 8 公尺以下的小段各自擺（`world.js` 的 `seg`），不然彎路上會對不齊。

## 道路規格
- `ROAD_V[i]`（縱向）、`ROAD_H[j]`（橫向）各 7 條，型別 L／M／S：車道寬由中線往外為 L 3.3、3.3、4.6，M 3.4、4.6，S 4.6，再加 0.4 公尺路面邊線空間。`road.half` 半寬、`road.lanes` 各車道中心、`road.bounds` 車道線位置。
- 不要再用全域的路寬常數；要用 `ownRoad(d, i, j)`（自己這條路）與 `crossRoad(d, i, j)`（交叉的那條路）。
- 路口：轉角圓角半徑 `cornerR(i, j)`（有大道 10、兩條巷道 6、其餘 8 公尺）；圓角讓路緣退後，路口附近要擺東西在人行道上時用 `curbBack(R, u)` 算退了多少；斑馬線在路口邊緣外 3～6 公尺；停止線 6.8 公尺；有機車停等區（有紅綠燈且至少兩線）時汽車停止線再退 4.2 公尺。`stopDist(d, i, j, scooter)` 算停止線離路口中心的距離。
- 關卡路線主要走第 1、3、5 條；第 2、4 條縱向與第 4 條橫向是巷道。改路型後要檢查 `js/levels.js` 的路線。

## 已知的小瑕疵
- 其他車輛右轉時會稍微切到轉角人行道（中心超出約 0.6 公尺），只是外觀問題。
- 標線、號誌的橫向是照格子方向推歪的，在斜路口停止線會跟橫向道路平行而不是垂直於車道。
