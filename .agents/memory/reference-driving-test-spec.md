# 大客車場考的通用尺寸與評分

駕訓班關卡用的通用（官方）規格。2026-11-12 查到的。路線順序與場地照片見 [reference-driving-school-map.md](reference-driving-school-map.md)。

## 來源
- 中華民國汽車駕駛教育學會網站上的公路總局文件（101 年 7 月，文號 101HC05332），內含「汽車駕駛人考驗場規格標準規範修正對照表」與「汽車駕駛人路考評分標準暨成績紀錄表（修正案）」：`https://drivingroc.org.tw/sites/default/files/1-50.pdf`（第 17 頁是評分表，第 24 頁是曲線進退規格表）。用 curl 抓得下來，用 `pdftotext -table` 抽文字最整齊。
- 這份是 2012 年的版本。之後有修正（例如新聞提到場考加考停讓行人），沒查到最新的全文，數字以這份為準、有疑問再跟使用者確認。
- 查不到的來源：各區監理所網站（`*.thb.gov.tw`）有機器人驗證，自動化工具進不去，要使用者自己開；臺北市法規查詢系統的設備表 PDF 回 404。

## 有官方數字的項目

### 曲線進退（S 型），大客車與大貨車欄，單位公尺
| 代號 | 名稱 | 數值 |
|---|---|---|
| a | 端線垂直距 | 16.2 |
| b | 車道寬 | 5.5 |
| c | 圓心距（兩個圓心 e 到 e'） | 18.5 |
| d | 彎道寬 | 5.2 |
| R1 | 外壓管半徑 | 11.85 |
| R2 | 內壓管半徑 | 6.65 |
| R3 | 外安全島半徑 | 12.5 |
| R4 | 內安全島半徑 | 6.0 |
| R5 | 出入口安全島弧半徑 | 4.0 |
| l | 終點停車距離 | 9.0 以上 |

- 科目是正 S 形：兩個反向的圓弧接起來，圓心相距 18.5。彎道寬 5.2 就是 R1 減 R2。
- 彎道兩邊由橡皮壓管內緣向外漆 0.1 公尺寬的實線。
- 出入口的啟動管與車道線平行，延伸線通過圓心並與外壓管圓相切。
- 對照：普通小型車是 a 6.4、b 3.5、c 9.0、d 3.2、R1 6.1、R2 2.9。
- 現行公車長 12、寬 2.5、軸距 6。開工時要先確認現行的最大轉向角過得了內半徑 6.65、外半徑 11.85 的彎。使用者決定（2026-11-12）：先用現行的車做，做的時候發現有關卡過不去，再改車長、軸距。

### 其他項目裡出現的數字（都出自評分表）
- 換檔穩定測試（直線換檔）：在 45 公尺的壓管範圍內依序換到 3 檔。
- 上下坡道：上坡倒退 15 公分以上算扣分；要在限定範圍內停車。
- 上下坡道的尺寸（使用者 2026-11-12 指定，先照這個做）：坡度至少 10%，坡長至少 30 公尺。
- 鐵路平交道：看到標誌或標線後車速要降到 15 公里以下，要停車察看。

## 沒查到官方數字的項目
倒車入庫的車庫長寬、平行路邊停車的車格長寬、曲巷調頭的巷寬與長度、狹橋的寬度與長度、直線換檔的車道寬。規範本文沒找到，只找到修正對照表。使用者決定（2026-11-12）：這些項目參照大新店的衛星圖與比例自訂尺寸（圖片與比例見 reference-driving-school-map.md），再對照車長 12、車寬 2.5 確認開得過。在程式裡集中成常數，之後拿到官方數字好改。
