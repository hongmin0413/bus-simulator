# 手排公車模擬器

線上版：https://hongmin0413.github.io/bus-simulator/

原創的 3D 手排公車駕駛遊戲，純前端網頁（HTML + CSS + ES module + Three.js），目標是在手機瀏覽器橫放遊玩，電腦上也能用鍵盤玩。

- 手排 6 速 + R，離合器是類比的：要自己慢慢放才能平順起步，放太快會頓一下甚至熄火。
- 公車是 12 公尺級的甲類大客車（寬 2.5、軸距 6、前懸 2.7、後懸 3.3 公尺），最多載 65 人，乘客越多加速越慢、煞車距離越長。
- 旋轉手機當方向盤，左駕，有左右後照鏡與照車頭死角的廣角圓鏡。開場要踩離合器按「發動」。
- 三個關卡，依序停靠各站載客，跑完一圈依收入結算星等。
- 路況參考台灣街頭：大道、一般道路與巷道，路會彎；紅燈倒數與行人號誌、機車停等區、機車鑽車縫、兩段式左轉與待轉區、計程車、藍色小貨車、路邊違停、行人走斑馬線。
- 要守交通規則：闖紅燈、超速、逆向、沒打方向燈都會扣錢。
- 聲音全部用 Web Audio 合成，沒有任何音效檔。

## 在自己的電腦上啟動

需要先安裝 [Node.js](https://nodejs.org/)。

- Windows：點兩下 `start.bat`，確認伺服器連得上之後會自動開啟瀏覽器。
- 其他系統：執行 `npm start`（或 `node server.js`），再開 `http://localhost:8765/`。

不需要 `npm install`，Three.js 已經放在 `lib/` 裡。

啟動後會開兩個埠：

| 用途 | 網址 |
|---|---|
| 電腦 | `http://localhost:8765/` |
| 手機 | `https://<電腦的區域網路 IP>:8766/` |

## 在手機上玩（連自己的電腦）

1. 手機和電腦連同一個網路。
2. 電腦執行 `start.bat`，視窗會列出手機要開的網址（電腦有多張網卡時會列出好幾個，選和手機同網段的那個）。
3. 手機瀏覽器開那個 `https://…:8766/` 網址。憑證是啟動時自動產生的自簽憑證，第一次會出現「連線不是私人連線」，按「進階」→「繼續前往」。
4. 手機橫放，選關卡開始。

手機一定要用 HTTPS 那個網址，瀏覽器才會提供傾斜感應；用 HTTP 開只能在畫面上拖曳轉向。產生憑證用的是 Git for Windows 內附的 openssl。

## 操作

### 手機

| 位置 | 控制 |
|---|---|
| 左下 | 方向燈 ◀ ▶（上）、離合器（下） |
| 右下 | 車門／視角／校正、拖曳式排檔（上排 1 3 5、中間橫槽是空檔、下排 R 2 4 6）、煞車、油門 |
| 中下 | 手煞車 P、時速表、檔位與警示燈（手煞車、車門、下車鈴）、轉速表、發動鈕；上方是方向燈指示燈、雙黃燈開關、喇叭 |
| 上排 | 左後照鏡、收入與乘客、暫停與全螢幕切換、下一站、小地圖、圓鏡、右後照鏡 |

- 離合器、煞車、油門都是按得越靠上踩得越深。
- 換檔要先把離合器踩到底，再按住排檔桿往想要的檔位拖。不用照著槽走，從現在的位置直接拖過去就行（1 檔可以直接往下拉到 2 檔、2 檔往右上拖進 3 檔），拖到中間是空檔。R 檔有擋塊：要先回空檔，在中間的橫槽往左多推一點才進得去（不用放手）。
- 開場引擎是熄火的：離合器踩到底，按住「發動」約一秒到引擎點著。熄火後也是這樣重新發動。引擎運轉中、車子停住時再按一次是熄火。
- 手煞車開場是拉起的，起步前要放開。
- 轉彎、變換車道、進站（右燈）、出站起步（左燈）前要打方向燈。
- 暫停選單可以繼續、重新開始、換關卡（可以取消回到暫停選單）、調整轉向靈敏度、切換畫面（省電每秒 30 格，手機比較不燙；流暢每秒 60 格）。
- 按「視角」可切到車外，在車外時一指拖曳可以繞著公車看、兩指捏合可以縮放，切換後會記住位置。
- 開啟網頁後第一次點畫面就會進全螢幕（瀏覽器不允許網頁一載入就自動全螢幕）；開始畫面和遊戲畫面都有切換全螢幕的按鈕。

### 鍵盤

| 按鍵 | 功能 |
|---|---|
| W / S | 油門 / 煞車（按住越久踩越深，放開慢慢回彈） |
| A / D | 方向盤 |
| Shift | 離合器（1、2、R 檔起步與行進間換檔會自動慢放；靜止時用 3～6 檔起步、手煞車沒放、車門沒關、還踩著煞車都不會，會熄火） |
| Enter | 發動引擎（要先按住 Shift 踩離合器）；引擎運轉中、車子停住時是熄火 |
| 1–6 / R / N | 檔位 |
| 空白鍵 | 手煞車 |
| Q / E / H | 左方向燈 / 右方向燈 / 雙黃燈 |
| G | 喇叭（按住才響） |
| F / C | 車門 / 視角（車外視角用滑鼠拖曳轉動、滾輪縮放） |
| P | 暫停 |
| Backspace | 回上一站 |
| M | 靜音 |

## 檔案結構

```
index.html      畫面結構
css/style.css   樣式
js/             遊戲模組，進入點是 main.js；各檔職責寫在第一行註解
js/levels.js    關卡設定，新增關卡只要加一筆
lib/            Three.js 0.160.0（MIT 授權，授權條款在 lib/three.LICENSE.txt）
manifest.webmanifest、icon.svg   「加到主畫面」用的設定與圖示
images/og-image.png   社群分享時顯示的圖片
server.js       本機靜態檔案伺服器（HTTP 8765、HTTPS 8766），線上版用不到
start.bat       Windows 點兩下啟動
AGENTS.md       給 AI 助理的專案規則
.agents/        AI 助理的工作日誌與記憶
```

沒有建置步驟，也沒有需要安裝的套件。
